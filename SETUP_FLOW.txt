                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│  Step 1: Clone/Download Repository                       │

                             │
                             ▼

                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│  Step 3: Configure Video URL                             │
│  ├─ Edit config.json                                     │

└─────────────────────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│  Step 4: Verify Setup (Optional)                         │
│  ├─ python verify_setup.py                              │

└─────────────────────────────────────────────────────────┘
                             │
                             ▼

│  ├─ Plays videos                                         │

Troubleshooting:
================
- Dependencies won't install? → Try: pip install --user -r requirements.txt
- Python not found? → Try: python3 setup.py
- Config errors? → Run: python verify_setup.py
- Need help? → Check: SETUP_GUIDE.md
